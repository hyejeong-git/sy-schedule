# 소율이 일정

소율이 일정을 엄마·아빠·할머니가 함께 보는 웹앱(PWA)입니다.

## 기능
- 달력: 어린이집·병원 등 일정 직접 입력, 날짜별 날씨(기온·강수확률·비/눈 알림)
- 학원: 학원 이름·수업 요일·납부 방식을 직접 등록
  - N개월마다 같은 날짜 / 매달 정해진 기간(예: 18~23일) / N회 수업마다(예: 13회)
  - 납부일을 기록하면 다음 납부일이 달력에 💰로 표시
  - 결석·휴강은 회차에 세지 않아 납부일이 뒤로 밀리고, 보강은 달력에서 추가
- 식단: 어린이집 월간 식단표를 Claude에게 보내주면 월~금 오전간식·점심·오후간식을 읽어 `src/data/meals/yyyy-MM.json`으로 앱에 넣습니다. 앱에서는 보기와 고치기만 가능 (고친 내용은 저장 후 포함된 식단보다 우선)
- 글자 크기: 설정에서 4단계 + 슬라이더 (기기별 저장)

## 실행
```bash
npm install
npm run dev
npm test
```
Firebase 설정 없이 실행하면 **이 기기에만** 저장됩니다(체험용).

## 가족과 공유하기 (Firebase, 무료)
1. https://console.firebase.google.com 에서 프로젝트 생성
2. **Authentication → 로그인 방법 → 익명** 사용 설정
3. **Firestore Database** 생성 후 `firestore.rules` 내용을 규칙에 붙여넣고 게시
4. 프로젝트 설정 → 내 앱 → 웹 앱 추가 → 설정값을 `.env.example`을 참고해 `.env`로 저장
5. 앱을 열면 **가족 코드**를 묻습니다. 가족 모두 같은 코드를 입력하세요(6글자 이상, 남에게 알리지 않기).

## 배포 (GitHub Pages)
1. 저장소 Settings → Pages → Source를 **GitHub Actions**로 설정
2. Settings → Secrets and variables → Actions → **Variables**에 `VITE_FIREBASE_*` 4개 등록
3. `main`에 push하면 자동 배포됩니다. 폰 브라우저에서 열고 "홈 화면에 추가"하면 앱처럼 사용할 수 있습니다.
